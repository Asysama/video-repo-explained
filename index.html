2026-11-08 · 全部基于本地 checkout 的源码逐行调研，页面上每个数字都标了出处。

页面 仓库 一句话结论
LTX-Video (v0.9.x) github.com/Lightricks/LTX-Video 已退休的 DiT 视频生成代码库：两遍多尺度渲染、CFG 是一条按时间分档的曲线、默认参数指向不存在的文件
Wan2.2 github.com/Wan-Video/Wan2.2 那个"MoE"其实是两份完整权重在时间轴上换班；参数是 meta device 实测出来的
NVIDIA Cosmos github.com/NVIDIA/cosmos 零代码的落地页：只有规格与测速表，质量分数一个都没有

三者的共同点

  • 都是 DiT + 视频 VAE + 文本编码器的当代架构
  • 三家的核心数字都被实测/复算过：LTX 的 2B = 2,397,046,912；Wan 的 14B = 14,288,491,584；Cosmos 只有声明的 4B / 16B / 64B
  • 三家都把真正的训练代码放在了别处，这三个仓库全是推理侧的
  • 三家的 README 都比代码更"热闹"：宣传的能力和仓库里能跑通的东西之间存在明显落差
